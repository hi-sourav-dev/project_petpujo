# PetPujo - College Canteen Food Booking System

PetPujo is a full-stack online food booking and ordering system developed for a college canteen. It allows students to browse the food menu, select food items, manage their cart, place orders, and make online payments.

The project is designed to make the college canteen food ordering process easier, faster, and more convenient for students.

---

## Features

- User Registration
- User Login
- User Authentication
- Session Management
- Food Menu
- Food Categories
- Food Item Images
- Add Food Items to Cart
- Increase Food Quantity
- Decrease Food Quantity
- Remove Items from Cart
- Cart Total Calculation
- Online Food Booking
- Razorpay Online Payment
- Payment Verification
- Payment Receipt
- Order/Payment Information
- MongoDB Database
- Image Upload
- Backend REST APIs
- Email Support/Notification
- Responsive User Interface
